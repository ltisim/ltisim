# Use of the LTISim name

The code in this repository is open source under the Apache License 2.0. The name is not.

"LTISim" identifies this project and the hosted service run by its owner, Tim Schwichtenberg. The Apache License explicitly does not grant rights to a project's names or marks.

## You may

- Say that your installation runs LTISim, when it runs this software unmodified or with your own configuration.
- Say that your product is "based on LTISim" or "compatible with LTISim", when that is true.
- Refer to LTISim by name in articles, talks, courses and documentation.

## You may not, without written permission

- Distribute a modified version under the name LTISim, or under a name likely to be confused with it. A fork must choose a different name.
- Offer a hosted service called LTISim, or imply that your service is the official one.
- Use the name in a way that suggests the project or its owner endorses you.
